# Как выложить сайт RUSSONLINEUZ в интернет

Простая инструкция: от кода на компьютере до работающего сайта на своём домене.
Займёт около получаса, плюс ожидание, пока заработает домен (до суток).

Сайт размещаем на **Netlify** — бесплатный тариф разрешает коммерческие сайты
(у Vercel бесплатный тариф — только для личных некоммерческих проектов).
Сайт обновляется сам каждый раз, когда вы отправляете изменения в GitHub.

---

## Что понадобится

1. Аккаунт на **GitHub** — github.com (бесплатно). Там хранится код сайта.
2. Аккаунт на **Netlify** — netlify.com. Входите через «Sign up with GitHub», так проще.
3. Токен Telegram-бота и ID чата, куда приходят заявки (см. шаг 3).
4. Свой **домен** — можно позже, сайт сначала заработает на адресе `….netlify.app`.

---

## Шаг 1. Загрузить код на GitHub

1. На github.com нажмите **New repository**.
2. Название: `russonlineuz`. Выберите **Private** (закрытый). Больше ничего не отмечайте.
3. Нажмите **Create repository**. GitHub покажет адрес вида
   `https://github.com/ВАШ-ЛОГИН/russonlineuz.git`.
4. На компьютере откройте терминал в папке `russonlineuz/russonlineuz` и выполните
   (подставьте свой адрес):

   ```bash
   git remote add origin https://github.com/ВАШ-ЛОГИН/russonlineuz.git
   git push -u origin main
   ```

   При первом запуске откроется окно входа в GitHub — войдите.

Файл `site/.env` с токеном бота в GitHub **не попадает** — так и задумано.

---

## Шаг 2. Подключить проект в Netlify

1. На netlify.com нажмите **Add new project → Import an existing project**
   (в некоторых версиях интерфейса — **Add new site**).
2. Выберите **GitHub** и разрешите Netlify доступ к репозиторию `russonlineuz`.
3. Выберите репозиторий. **Важно:** в поле **Base directory** впишите `site`.
   Остальное (команда `npm run build`, папка `dist`) Netlify возьмёт сам из файла
   `site/netlify.toml` — эти поля не трогайте.
4. Нажмите **Add environment variables** и добавьте (шаг 3 — где взять значения):

   | Key | Value |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
   | `TELEGRAM_CHAT_ID` | ID чата, куда приходят заявки |

   Области действия (scopes) оставьте по умолчанию — **все**.
5. Нажмите **Deploy** и подождите 1–3 минуты.
6. Netlify покажет адрес вида `случайное-имя.netlify.app` — сайт уже работает по нему.
   Имя можно поменять: **Site configuration → Change site name** → `russonlineuz`
   (тогда адрес станет `russonlineuz.netlify.app`). После смены имени сделайте
   пересборку (см. «Как пересобрать сайт» ниже).

---

## Как пересобрать сайт

Нужно после изменения переменных окружения, имени сайта или подключения домена:
**Deploys → Trigger deploy → Deploy site**.

---

## Шаг 3. Заявки должны приходить Назокат

Если сейчас стоит тестовый чат, переключите заявки на учителя:

1. Назокат открывает в Telegram вашего бота и пишет ему `/start`.
2. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates`
   (вместо `ТОКЕН` — токен бота).
3. Найдите сообщение Назокат и в нём `"chat":{"id": ЧИСЛО` — это её ID.
4. В Netlify: **Site configuration → Environment variables** → `TELEGRAM_CHAT_ID` →
   **Edit** → вставьте число → **Save**.
5. Пересоберите сайт (**Deploys → Trigger deploy → Deploy site**).

Можно сделать и группу «Заявки RUSSONLINEUZ»: добавить туда бота и Назокат, написать
в группе сообщение и взять ID группы тем же способом (он начинается с минуса).

**Проверка:** откройте сайт с телефона и отправьте тестовую заявку — она должна прийти
в Telegram за пару секунд.

---

## Шаг 4. Подключить свой домен (когда купите)

1. Купите домен (например, `russonline.uz`) на webname.uz или ahost.uz.
2. В Netlify: **Domain management → Add a domain** → введите домен → подтвердите.
   Netlify предложит добавить и `www` — соглашайтесь.
3. Netlify покажет, какие **DNS-записи** нужно создать у регистратора (обычно запись `A`
   для домена и `CNAME` для `www`). Скопируйте значения **именно оттуда**.
4. В панели регистратора домена откройте управление DNS и создайте эти записи.
5. Подождите от 15 минут до суток. Когда домен в Netlify станет активным, нажмите там
   **Verify DNS / Provision certificate**, если кнопка есть — замок HTTPS включится сам.
6. Пересоберите сайт (**Deploys → Trigger deploy → Deploy site**). Сайт сам возьмёт новый
   адрес у Netlify — от него зависят карта сайта и картинки в превью ссылок.
   Код менять не нужно.

---

## Шаг 5. Подключить аналитику (когда будете готовы)

1. Создайте счётчики:
   - **Яндекс Метрика** — metrika.yandex.ru → «Добавить счётчик», включите Вебвизор;
   - **Google Analytics 4** — analytics.google.com, ID вида `G-XXXXXXX`;
   - **Meta Pixel** — business.facebook.com → Events Manager.
2. В Netlify → **Site configuration → Environment variables** добавьте те, что создали:
   `PUBLIC_YM_ID`, `PUBLIC_GA4_ID`, `PUBLIC_META_PIXEL_ID`.
3. Пересоберите сайт.

Сайт сам отправляет события: `lead` (заявка отправлена), `choose_tariff`, `click_telegram`,
`click_instagram`, `click_demo` (канал демо-уроков), `click_results` (канал результатов),
`switch_lang`. В Метрике создайте цели с такими же названиями
(тип «JavaScript-событие»).

---

## Шаг 6. Как обновлять сайт

1. Измените файлы (тексты — в `site/src/i18n/uz.json` и `ru.json`, цены —
   в `site/src/data/tariffs.json`).
2. Отправьте изменения:

   ```bash
   git add -A
   git commit -m "Коротко: что изменили"
   git push
   ```

3. Через 1–3 минуты Netlify сам выложит новую версию. Если что-то сломалось —
   в **Deploys** откройте прошлую удачную выкладку и нажмите **Publish deploy**.

Найти их все: поиск по слову `ЗАПОЛНИТЬ` в папке `site/src`.
