## 2. Стиль
- Плоский вектор, **без обводки**, без теней и градиентов (по моушн-гайду). Формы — круги и скругления 24+ px.
- Не больше 4 цветов на персонажа, только палитра: кожа #F2B5A3, волосы и контуры деталей #1F2D4D, одежда — синий/терракота/кремовый.
- Лицо: глаза-точки, брови-дуги задают эмоцию, рот — 4 формы (закрыт, открыт, «О», улыбка). Нос — маленькая дуга или нет.
- **Эмоции (6):** радость, смущение (румянец #E07A5F), удивление, задумчивость, гордость, «упс» (ошибка).
- **Позы (6):** стоит, машет, указывает, держит телефон, сидит за ноутбуком, «класс» (большой палец).
- **Фоны (4):** магазин, такси, офис, Zoom-экран — 2–3 плоские формы, без текста, герои в зоне x 72–920.

## 3. Техника
- **SVG-кодом в React** (основное): каждый персонаж — компонент с группами `head`, `brows`, `eyes`, `mouth`, `armL/armR`, `body`; пропсы `emotion`, `pose`, `mouth`. Моргание раз в ~3 с, «говорение» — смена форм рта по таймингу фраз, руки — `rotate` вокруг плеча через `spring`.
- **Lottie** — только мелочи: конфетти, «искорки», иконки. Только свои или с проверенной лицензией.
- **Figma не обязателен**; полезен владельцу для эскизов и утверждения лиц. Экспорт SVG → чистка → компонент.
- **Установить** (версии = текущему Remotion 4.0.540):
  - `@remotion/lottie` + `lottie-web` — проигрывание Lottie внутри Remotion;
  - `@remotion/paths` — длина и морфинг контуров (рот, брови, рисование линией);
  - `@remotion/shapes` — готовые круги, прямоугольники, «звёзды» для фонов;
  - `svgo` (dev) — чистка SVG из Figma/Inkscape.
  Скилы и плагины не нужны; при желании — Remotion Agent Skills для подсказок по API.

## 4. Риски
- **Узнаваемость:** персонаж Ustoz связывает бренд с Назокат — нужно её письменное согласие на образ и одобрение эскиза.
- **Этика:** без карикатуры, без стереотипов о профессиях и национальности; «Собеседник» не высмеивается.
- **Палитра:** кожа только персиковая — условно, не реалистично; принимаем как стиль.
- **Сложность:** риг 4 персонажей ≈ 2–3 дня; начинаем с Ustoz + Aziz, остальных — после первого ролика.
- **Баланс:** анимация не заменяет живое лицо Назокат (личный бренд) — 1 моушн-ролик на 2–3 съёмочных.
