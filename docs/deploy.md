# Как выложить сайт RUSSONLINEUZ в интернет

Простая инструкция: от кода на компьютере до работающего сайта на своём домене.
Займёт около часа, плюс ожидание, пока заработает домен (до суток).

Сайт размещаем на **Vercel** — бесплатно, без ежемесячной подписки. Сайт обновляется
сам каждый раз, когда вы отправляете изменения в GitHub.

---

## Что понадобится

1. Аккаунт на **GitHub** — github.com (бесплатно). Там хранится код сайта.
2. Аккаунт на **Vercel** — vercel.com. Входите через «Continue with GitHub», так проще.
3. **Домен**, например `russonline.uz` — покупается на webname.uz или ahost.uz.
4. Токен Telegram-бота и ID чата Назокат (см. шаг 3).

---

## Шаг 1. Загрузить код на GitHub

1. На github.com нажмите **New repository**.
2. Название: `russonlineuz`. Выберите **Private** (закрытый). Больше ничего не отмечайте.
3. Нажмите **Create repository**. GitHub покажет адрес вида
   `https://github.com/ВАШ-ЛОГИН/russonlineuz.git`.
4. На компьютере откройте терминал в папке `russonlineuz/russonlineuz` и выполните
   (подставьте свой адрес):

   ```bash
   git remote add origin https://github.com/ВАШ-ЛОГИН/russonlineuz.git
   git push -u origin main
   ```

   При первом запуске откроется окно входа в GitHub — войдите.

Файл `site/.env` с токеном бота в GitHub **не попадает** — так и задумано.

---

## Шаг 2. Подключить проект в Vercel

1. На vercel.com нажмите **Add New… → Project**.
2. Найдите репозиторий `russonlineuz` и нажмите **Import**.
3. **Важно:** в поле **Root Directory** нажмите **Edit** и выберите папку `site`.
   Framework Vercel определит сам — **Astro**.
4. Откройте **Environment Variables** и добавьте (шаг 3 — где взять значения):

   | Name | Value |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
   | `TELEGRAM_CHAT_ID` | ID чата, куда приходят заявки |

5. Нажмите **Deploy** и подождите 1–2 минуты.
6. Vercel покажет адрес вида `russonlineuz.vercel.app` — сайт уже работает по нему.

---

## Шаг 3. Заявки должны приходить Назокат

Сейчас в настройках стоит тестовый чат. Чтобы заявки шли учителю:

1. Назокат открывает в Telegram вашего бота и пишет ему `/start`.
2. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates`
   (вместо `ТОКЕН` — токен бота).
3. Найдите сообщение Назокат и в нём `"chat":{"id": ЧИСЛО` — это её ID.
4. В Vercel: **Settings → Environment Variables** → измените `TELEGRAM_CHAT_ID`
   на это число → **Save**.
5. **Deployments** → у последней выкладки нажмите **⋯ → Redeploy**.

Можно сделать и группу «Заявки RUSSONLINEUZ»: добавить туда бота и Назокат, написать
в группе сообщение и взять ID группы тем же способом (он начинается с минуса).

**Проверка:** откройте сайт с телефона и отправьте тестовую заявку — она должна прийти
в Telegram за пару секунд.

---

## Шаг 4. Подключить свой домен

1. Купите домен (например, `russonline.uz`) на webname.uz или ahost.uz.
2. В Vercel: проект → **Settings → Domains** → введите `russonline.uz` → **Add**.
   Vercel предложит добавить и `www.russonline.uz` — соглашайтесь.
3. Vercel покажет, какие **DNS-записи** нужно создать (обычно запись `A` для домена
   и `CNAME` для `www`). Скопируйте значения **именно оттуда**.
4. В панели регистратора домена откройте управление DNS и создайте эти записи.
5. Подождите от 15 минут до суток. Когда в Vercel рядом с доменом появится зелёная
   галочка — сайт открывается по вашему адресу. Замок HTTPS Vercel включит сам.

**Если домен не `russonline.uz`:** в файле `site/astro.config.mjs` замените адрес
в строке `site: 'https://russonline.uz'` на свой и отправьте изменения (шаг 6).
От этого адреса зависят карта сайта и красивые превью ссылок.

---

## Шаг 5. Подключить аналитику (когда будете готовы)

1. Создайте счётчики:
   - **Яндекс Метрика** — metrika.yandex.ru → «Добавить счётчик», включите Вебвизор;
   - **Google Analytics 4** — analytics.google.com, ID вида `G-XXXXXXX`;
   - **Meta Pixel** — business.facebook.com → Events Manager.
2. В Vercel → **Settings → Environment Variables** добавьте те, что создали:
   `PUBLIC_YM_ID`, `PUBLIC_GA4_ID`, `PUBLIC_META_PIXEL_ID`.
3. Сделайте **Redeploy** (как в шаге 3).

Сайт сам отправляет события: `lead` (заявка отправлена), `choose_tariff`, `click_telegram`,
`click_instagram`, `switch_lang`. В Метрике создайте цели с такими же названиями
(тип «JavaScript-событие»).

---

## Шаг 6. Как обновлять сайт

1. Измените файлы (тексты — в `site/src/i18n/uz.json` и `ru.json`, цены —
   в `site/src/data/tariffs.json`).
2. Отправьте изменения:

   ```bash
   git add -A
   git commit -m "Коротко: что изменили"
   git push
   ```

3. Через 1–2 минуты Vercel сам выложит новую версию. Если что-то сломалось —
   в **Deployments** можно вернуть прошлую версию кнопкой **Promote to Production**.

---

## Чек-лист перед запуском

- [ ] Фото Назокат (портрет на светлом фоне) — вместо плейсхолдеров на главной и в блоке «Ustoz»
- [ ] Текст «о себе», опыт, образование, сколько учеников обучено
- [ ] Способы оплаты и правило переноса уроков (раздел «Вопросы»)
- [ ] Телефон в подвале
- [ ] Владелец (ФИО / ИП, ИНН) и срок хранения данных в политике конфиденциальности
- [ ] `TELEGRAM_CHAT_ID` — чат Назокат, а не тестовый
- [ ] Свой домен подключён, адрес в `astro.config.mjs` совпадает
- [ ] Отзывы учеников (когда появятся — блок пока скрыт)
- [ ] Показать политику и схему «заявка → Telegram, хостинг Vercel» юристу: в Узбекистане
      есть требования к хранению персональных данных граждан на серверах внутри страны

Все незаполненные места на сайте подсвечены жёлтым и помечены `[ЗАПОЛНИТЬ]`.
Найти их все: поиск по слову `ЗАПОЛНИТЬ` в папке `site/src`.
