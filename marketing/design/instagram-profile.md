# Оформление Instagram @russonlineuz — шапка и Highlights

Ноябрь 2026. Основа: личный бренд Назокат Юсуповой и [разбор аккаунтов-лидеров](../instagram-benchmark-2026-11.md).
Ничего не меняем в профиле без согласия владельца. Узбекские тексты — вычитать носителем перед публикацией.

## Аватар

Оставляем **фото Назокат** (как сейчас): лицо крупно, светлый фон, улыбка. Это личный бренд — у всех лидеров на аватаре лицо учителя.
Логотип-облачка из брендбука остаётся для сайта, Telegram-канала и рекламы.

## Имя профиля (поле «Имя», ищется в поиске Instagram)

```
NAZOKAT YUSUPOVA | RUS TILI 🇷🇺 ONLINE DARS
```
Оставляем как есть (42 символа из 64): имя + «RUS TILI» — по этим словам ищут.

## Описание (до 150 символов)

### Итог голосования команды (03.11): вариант C с правками — 4 голоса из 5

| Агент | Голос | Главный довод |
|---|---|---|
| sales-coach | C | Первая строка отвечает на «это для меня?» и снимает «я совсем с нуля» |
| ads-specialist | C | ish / oʻqish / hayot совпадают с аудиториями будущих кампаний |
| brand-designer | C | Спокойный ритм без 🔹 и флага рядом с яркими Highlights |
| content-creator | C | «Noldan» в начале; в A связка «tajriba · qoʻrqmaysiz» звучит нелогично |
| marketing-strategist | A | Отличие «oʻzim oʻtaman» должно быть видно до «ещё» |

Финальный текст (C + правки команды, 149 символов) — **утверждён владельцем 03.11**:
```
Noldan rus tili — ish, oʻqish, hayot uchun
Har bir jonli darsni oʻzim oʻtaman · Zoom
Guruh 5–6 kishi yoki individual · 5+ yil tajriba
1-dars bepul 👇
```
- Вторая строка — довод стратега: главное отличие «oʻzim oʻtaman» теперь в C.
- «yoki individual» — от продажника: не теряем тех, кому группа не подходит.
- Апостроф **ʻ** (U+02BB), а не ‘ — правка дизайнера и контент-мейкера.
- Перед публикацией: Назокат подтверждает «5+ yil»; носитель вычитывает; длина у самого лимита — проверить, что Instagram принимает текст целиком.
- Проверка цифрами (ads-specialist): ссылка в шапке с `utm_content=bio_c`, сравнить переходы и заявки с прошлым периодом; решение — от 300 посещений профиля.

### Исходные варианты

**Вариант A — рекомендую** (141 символ). Главное отличие от конкурентов в первой строке:
```
🔹Har bir darsni o‘zim o‘taman — jonli, Zoom’da
🔹Guruhda 5–6 kishi · noldan boshlaymiz
🔹5+ yil tajriba · gapirishdan qo‘rqmaysiz
👇1-dars bepul
```

**Вариант B — теплее, про страх** (120 символов):
```
Rus tilida gapirishdan qo‘rqmaysiz 🇷🇺
Har bir darsni o‘zim o‘taman · Zoom
Guruh 5–6 kishi yoki individual
1-dars bepul 👇
```

**Вариант C — про цели ученика** (129 символов):
```
Noldan rus tili — ish, o‘qish, hayot uchun
Har bir dars jonli va men bilan · Zoom
Guruh 5–6 kishi · 5+ yil tajriba
1-dars bepul 👇
```

Почему так:
- «Har bir darsni o‘zim o‘taman» — то, чего нет у конкурентов (у крупного курса лично с автором 6 занятий из десятков).
- «5–6 kishi» — у конкурентов группы 14–16.
- Нет обещаний «с первого урока заговорите» — по брендбуку только честные сроки.
- «5+ yil tajriba» уже стоит в текущей шапке; если появится подтверждённое число учеников — добавим.
